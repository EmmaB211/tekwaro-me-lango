# Tekwaro me Lango

A responsive static website prototype for a community-guided digital home for Lango heritage, language and stories.

## Website audit and current scope

The site is plain HTML, CSS and JavaScript hosted on GitHub Pages. It has responsive navigation, an archive topic filter and search, a Leb Lango dictionary interface with an explicit empty state, and a client-side-only contribution form demonstration.

No reviewed history, clan profiles, language entries, oral-history recordings, real event listings, leadership profiles or official strategic documents were available in the project. The site therefore makes no specific historical, genealogical, translation, pronunciation or leadership claims. Its topic areas are editorial scaffolds, not published records. The 50-year vision is explicitly awaiting authorized approval.

Stock images have been removed from the site. Abstract placeholders are used until photographs, locations, captions, credits and permissions are confirmed for publication. The Lango emblem supplied in the images folder is used as the brand mark.

## Preview locally

Open `index.html` in a browser. No build step or package installation is required. `governance.html` contains the public-facing editorial review and cultural-rights framework.

## GitHub Pages deployment

Push changes to `main`; `.github/workflows/deploy.yml` publishes the static site. The live site is [emmab211.github.io/tekwaro-me-lango](https://emmab211.github.io/tekwaro-me-lango/).

## Cultural review and content required

Before adding public material, obtain:

- Authorized institutional background, leadership, official vision, mission and approved 50-year strategic plan.
- Reviewed histories and source citations; any differing oral accounts should be represented with their source and context.
- Clan/community names, descriptions and access permissions reviewed by appropriate custodians.
- Leb Lango terms, meanings, examples and recordings reviewed by fluent speakers or language specialists.
- Oral histories with recorded consent, approved transcripts/translations, attribution and access level.
- Approved photographs/audio/video, captions, location/date where known, credits, rights and consent.
- Confirmed contact information and event/announcement approval.

Use the workflow and record fields in `governance.html`. Never commit confidential submissions, private contact details, consent records, restricted material or credentials to this public repository.

## Backend and privacy limitations

GitHub Pages is a public static host; it does not provide a secure content-management system, private review queue, contributor accounts, restricted archive, upload handling or form storage. The current form prevents a page reload for demonstration only and does not transmit or save its contents. Do not collect real submissions until authorized leadership selects a secure service and approves privacy, consent, access, retention, withdrawal, spam-protection and backup procedures.
