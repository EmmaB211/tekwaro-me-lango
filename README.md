# Tekwaro me Lango

A responsive, static website prototype for preserving and sharing Lango heritage, language, oral histories and community stories.

## Preview locally

Open `index.html` in a browser. The site uses plain HTML, CSS and JavaScript; no build step is required.

## GitHub Pages

The site is deployed automatically from the `main` branch using the workflow in `.github/workflows/deploy.yml`.

## Prototype limitations

The contribution form is a front-end demonstration only. It does not send or store submissions. The site does not yet include a CMS, administrator dashboard, or connected archive backend. Cultural stories and official positions should be reviewed and approved by community custodians before publication.
